사용자 · 검수 (일요일 중)
받은 5편 훑어보기
확인할 것 3가지:
  • 내용 톤·컴플라이언스 (수익률·환급률·상품명 언급 없는지)
  • pubDate 값 — 오늘 바로 노출하고 싶으면 오늘 날짜 이하로, 요일별로 예약 발행하고 싶으면 사이트가 미래 날짜 글을 실제로 숨겨주는지 먼저 확인 필요 (지금 사이트는 이 부분이 아직 미확인 상태)
  • 카드뉴스 이미지 5장 미리보기

사용자 · 배포
파일을 저장소에 넣고 push
muita-blog 저장소의 블로그 콘텐츠 폴더에 5개 마크다운 파일을 넣은 뒤, 맥 터미널(Terminal.app)에서 아래 순서대로 실행:
# 1) 저장소 폴더로 이동 (본인 실제 경로로 수정)
cd ~/muita-blog

# 2) 새 파일 5개가 잡히는지 확인
git status

# 3) 스테이징 + 커밋 + 푸시
git add .
git commit -m "주간 블로그 5편 추가 (YYYY-MM-DD)"
git push
💡 경로 모르면 Finder에서 폴더를 터미널 창으로 드래그
