이 블로그는 [Astro](https://astro.build)로 만들어졌습니다. 빠르고 간단한 정적 사이트 생성기입니다.

## 왜 Astro인가요?

- **빠른 속도** — 불필요한 자바스크립트를 보내지 않습니다
- **마크다운 지원** — 글 쓰기에 최적화된 워크플로우
- **확장성** — 필요하면 언제든 기능을 추가할 수 있습니다

## 이 블로그의 기능

1. 홈 페이지 (최신 글 표시)
2. 전체 글 목록
3. 글 상세 페이지
4. 태그별 필터링
5. RSS 피드
6. 모바일 대응 반응형 디자인
7. 다크 모드 자동 지원

## 코드 예시

```javascript
// 간단한 Astro 컴포넌트 예시
const greeting = "안녕하세요!";
console.log(greeting);
```
